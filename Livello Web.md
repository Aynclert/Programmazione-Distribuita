
I #componenti #Web Java EE sono #servlet o pagine Web create utilizzando la tecnologia #JSF e/o #JSP . 

Le #servlet sono classi Java che elaborano dinamicamente le richieste e costruiscono le risposte.

Le pagine #JSP sono documenti basati su testo che vengono eseguiti come #servlet ma consentono un approccio più naturale alla creazione di contenuto statico.

La tecnologia #JSF si basa su #servlet e tecnologia #JSP e fornisce una struttura di #componenti dell'interfaccia utente per le applicazioni #Web.

Il [[Livello Web]], così come il [[Livello Client]], potrebbe includere un componente #JavaBeans per gestire l'input dell'utente e inviare tale input ai [[Enterprise Java Bean]] in esecuzione nel [[Livello Business]] per l'elaborazione.
