
Le #applicazioni aziendali sono costituite da [[Enterprise Java Bean]], [[JMS]], Java Transacton API, chiamate asincrone, servizio timer, RMI/IIOP.

Il contenitore EJB è responsabile della gestione dell'esecuzione dei [[Enterprise Java Bean]] (bean di sessione e bean basati sui messaggi) contenenti il livello della logica di business dell'applicazione Java EE.
