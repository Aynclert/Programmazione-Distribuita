
Le #applicazioni sono programmi che vengono eseguiti su un #Client. Generalmente sono GUI o programmi di elaborazione batch che hanno accesso a tutte le funzionalità del livello intermedio Java EE.

Il contenitore del #client dell'applicazione include un set di classi Java, librerie e altri file necessari per portare l'iniezione, la gestione della sicurezza e il servizio di denominazione alle #applicazioni Java SE. In più comunica con:
- il [[Contenitore EJB]] utilizzando RMI/IIOP;
- il [[Contenitore Web]] con HTTP.
